# 😊📙 Emojipedia React App

A basic React application that displays a list of emojis with their titles and meanings. This app is static — it does not have any input fields, search functionality, or backend database. All emoji data is stored in a local JavaScript file (`emojipedia.js`).

---

## 📁 Features

- Displays a list of emojis
- Each emoji shows:
  - Emoji symbol
  - Title
  - Meaning
- No user input or search
- Purely static content from a JavaScript file
